# Field kit

Everything two team members need for six to eight fifteen-minute conversations with restaurant
owners. The method and the findings table are in [`../field_research.md`](../field_research.md).

| File | Use |
|---|---|
| [`consent_script.md`](consent_script.md) | Read first, in the owner's language; the team's privacy rules |
| [`question_sheet_en.md`](question_sheet_en.md) | The seven questions, grouped by part of the conversation (the original) |
| [`question_sheet_hi.md`](question_sheet_hi.md), [`question_sheet_gu.md`](question_sheet_gu.md) | Hindi and Gujarati drafts, to be checked by a native speaker before use |
| [`comprehension_cards.md`](comprehension_cards.md) | Today's offer report against TrueLift's weekly result; a forecast as a range or as a chance; the one-in-ten holdout |
| [`note_template.md`](note_template.md) | One page per interview, written within the hour |
| [`target_outlets.md`](target_outlets.md) | Fifteen outlets to reach eight; filled in locally, never committed |
| [`short_form.md`](short_form.md) | Five questions for a wider, lighter signal |

Print: the consent script and the question sheet in the owner's language, the three cards (card
2A or 2B by interview number), and blank note pages. Load the offline demo on two phones.
